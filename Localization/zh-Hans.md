# 简体中文术语与校对约定

从英文原文逐条翻译；中文译稿仍需母语用户在实际界面与 VoiceOver 中验收，不宣称已有人工审校签字。

- Channel — 频道
- Channel operator — 频道管理员
- Administrator — 服务器管理员
- Push-to-talk — 按键说话
- Voice activation — 语音激活
- Hear myself — 本地麦克风返听 — 不表示经过网络接收的声音
- Mute locally — 在本机静音 — 区别于禁止他人向频道发言
- Intercept — 监听 — 区别于普通接收
- Pan — 声像
- Solo — 独听
- Profile — 配置档案 — 独立设置、服务器和历史记录
- Kick — 移出 — 区别于封禁
- Ban — 封禁
- Preferences — 设置
- VoiceOver — VoiceOver — 保留系统功能名称

使用中文标点；按钮说明动作；状态说明结果；错误提供可执行的下一步。保留所有格式占位符、数值与快捷键。带序号占位符可按中文语序调整。语言名称“简体中文”在本语言中显示。
