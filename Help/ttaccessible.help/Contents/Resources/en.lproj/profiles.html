Profiles

A profile is a complete, separate copy of your configuration: its own saved servers, preferences, sound packs, chat history and stored passwords. Each profile runs in its own instance of the app, so you can be connected to two servers at once, or keep a work identity apart from a personal one.

The name of the current profile appears in the title of the TeamTalk Servers window.

Opening the profiles window

tt-Accessible → Manage Profiles…, or New Instance… (Shift-Command-N), opens Profiles. The list shows each profile's Name and Status — Current, Running or Default.

What you can do

Button Effect
Launch Starts a new instance with the selected profile — Return does the same
New… Creates a profile and launches it straight away
Duplicate… Copies an existing profile, with its servers, passwords, settings, chat history and sound packs
Rename… Changes the display name only; nothing is moved or copied
Delete Removes the profile and everything it contains — the Delete key does the same
Refresh Updates the statuses

The name Default is reserved.

Limits worth knowing

  • A profile cannot be duplicated or deleted while another instance is running with it. Quit that instance first.
  • The profile you are currently running cannot be deleted from that same instance — do it from another one.
  • Deleting a profile is permanent: its servers, preferences, sound packs, chat history and stored passwords go with it.
