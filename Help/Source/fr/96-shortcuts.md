Tout se fait au clavier dans tt-Accessible. Les raccourcis qui concernent une personne s'appliquent à
celle qui est sélectionnée dans l'arbre des canaux.

## Application

| Raccourci | Commande |
|---|---|
| Commande-virgule | Préférences |
| Commande-point d'interrogation | Aide tt-Accessible |
| Maj-Commande-N | Nouvelle instance… |

## Se déplacer

| Raccourci | Zone |
|---|---|
| Commande-1 | Zone principale — l'arbre des canaux, ou la liste des serveurs hors session |
| Commande-2 | Historique du chat |
| Commande-3 | Saisie du message |
| Commande-4 | Historique de session |
| Commande-5 | Mixeur du canal |

## Dans le lecteur média

| Touche | Action |
|---|---|
| Espace | Lecture ou pause |
| Échap | Arrêt |
| Flèche gauche / droite | Reculer ou avancer de 5 secondes |
| Flèche haut / bas | Volume diffusé |

## Dans le mixeur du canal

| Touche | Action |
|---|---|
| Flèche haut / bas | Volume de la voix |
| Flèche gauche / droite | Panoramique de la voix |
| Commande-Haut / Commande-Bas | Volume du média, ou volume principal hors d'une tranche |
| Commande-Gauche / Commande-Droite | Panoramique du média |
| V, P, M, S | Annoncent le volume, le panoramique, la sourdine ou le solo — deux appuis réinitialisent ou basculent |
| Commande-P | Annonce le panoramique du média — deux appuis le recentrent |

## Dans les listes

| Touche | Action |
|---|---|
| Entrée | L'action par défaut : rejoindre un canal, se connecter à un serveur, télécharger un fichier, modifier un compte, lancer un profil |
| Suppr | Supprimer un serveur, un fichier, un bannissement, un compte ou un profil |
| Échap | Fermer la fenêtre, ou annuler la boîte de dialogue |
