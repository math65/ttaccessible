tt-Accessible est un client TeamTalk 5 pour macOS pensé pour les utilisateurs de VoiceOver. Toutes
les fenêtres, toutes les listes et toutes les commandes s'atteignent au clavier, l'application
annonce ce qui se passe sur le serveur, et chaque personne que vous entendez se règle
individuellement.
