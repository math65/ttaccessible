tt-Accessible est un client TeamTalk 5 pour macOS conçu pour les utilisateurs de VoiceOver. Toutes
les fenêtres, toutes les listes et toutes les commandes s'atteignent au clavier, l'app annonce ce
qui se passe sur le serveur, et vous pouvez régler chaque personne que vous entendez.
