Everything in tt-Accessible can be done from the keyboard. Shortcuts that apply to a person act on
the one selected in the channel tree.

## Application

| Shortcut | Command |
|---|---|
| Command-comma | Preferences |
| Command-question mark | tt-Accessible Help |
| Shift-Command-N | New Instance… |

## Moving around

| Shortcut | Area |
|---|---|
| Command-1 | Main area — channel tree, or the server list when disconnected |
| Command-2 | Chat history |
| Command-3 | Message input |
| Command-4 | Session history |
| Command-5 | Channel Mixer |

## In the media player

| Key | Action |
|---|---|
| Space | Play or pause |
| Escape | Stop |
| Left / Right arrow | Seek 5 seconds |
| Up / Down arrow | Broadcast volume |

## In the channel mixer

| Key | Action |
|---|---|
| Up / Down arrow | Voice volume |
| Left / Right arrow | Voice pan |
| Command-Up / Command-Down | Media volume, or the master volume outside a strip |
| Command-Left / Command-Right | Media pan |
| V, P, M, S | Speak volume, pan, mute or solo — press twice to reset or toggle |
| Command-P | Speak the media pan — press twice to re-centre |

## In lists

| Key | Action |
|---|---|
| Return | The default action: join a channel, connect to a server, download a file, edit an account, launch a profile |
| Delete | Remove a server, a file, a ban, an account or a profile |
| Escape | Close the window, or cancel the sheet |
